## 📚 العمود الفقري المعرفي

### A. The Fundamentals Gate (لازم قبل أي framework)
بطاقات لـ 8 مفاهيم — كل بطاقة فيها: تعريف، مثال كود، تمرين micro، citation:
1. **Variables & Types** (primitive vs reference)
2. **Control Flow** (if, loops, recursion)
3. **Functions** (pure, impure, higher-order)
4. **Scope & Closures** (with JavaScript example)
5. **Async vs Sync** (event loop in 2 dakika)
6. **Memory Model** (stack vs heap basics)
7. **Big-O Notation** (visual comparison)
8. **Data Structures** (Array, Object/Hashmap, Stack, Queue, Tree — when to use each)

**Gate Quiz:** 10 أسئلة. لازم يحقق 70%+ قبل الانتقال للـ paths.

### B. Path Decision Tree
شجرة قرار interactive:
- "أحب تصاميم وتفاعلية؟" → Frontend
- "أحب أنظمة وقواعد بيانات؟" → Backend
- "أحب الاثنين؟" → Full-stack (لكن ابدأ بواحد)
- "أحب الموبايل؟" → Mobile (Flutter / React Native)
- "أحب الـ data؟" → Data path (خارج نطاق هذا الـ module — أشِر فقط)

### E. Git + GitHub — Survival Kit
بطاقات لـ 12 سيناريو شائع:
1. أول commit
2. branch + merge
3. resolve conflict
4. revert vs reset
5. cherry-pick
6. rebase (مع تحذير)
7. stash
8. tag للإصدارات
9. .gitignore أساسي
10. Pull Request etiquette
11. Code Review (كيف تقرأ ديف)
12. Recovery من خراب

كل سيناريو: الأمر + الشرح + خطر شائع.

### F. Clean Code Pillars (8 قواعد عملية)
1. **Naming** — أسماء واضحة من 2-4 كلمات، لا اختصارات mysterious
2. **Functions** — تفعل شيء واحد، ≤ 20 سطر مفضّلاً
3. **Comments** — اشرح "ليش" مو "ماذا"
4. **DRY** بحدود — Wet أحياناً أفضل من Dry قسرياً
5. **YAGNI** — لا تكتب لـ "ربما"
6. **Single Source of Truth**
7. **Composition over Inheritance**
8. **Fail Fast** — validate at boundaries

كل قاعدة: مثال سيئ مقابل جيد بكود حقيقي.

### G. Code Review Etiquette (10 قواعد)
- Focus on code, not coder
- Explain "why" in suggestions
- Use "we" instead of "you"
- Praise the good parts
- ... إلخ

### H. Soft Skills للمبرمج
- **Estimation** — قاعدة 3x للـ junior (متى ينطبق ومتى لا)
- **Asking Questions** — كيف تسأل سؤال جيد (StackOverflow style)
- **Standup** — 3 جمل (yesterday, today, blockers)
- **Saying "I don't know"** — كيف تقولها بثقة
- **Pair Programming** — الـ driver/navigator pattern
