# Thmanyah Premium Font (Self-Hosted, Optional)

Place the following files in this directory to enable the premium Display voice:

- `Thmanyah-Regular.woff2` (weight 400)
- `Thmanyah-Medium.woff2`  (weight 500)
- `Thmanyah-Bold.woff2`    (weight 700)
- `Thmanyah-Black.woff2`   (weight 900)

If these files are absent the platform silently falls back to **Reem Kufi**
(loaded from Google Fonts) — no errors, no broken UI.
